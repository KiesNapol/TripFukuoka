# Kyushu, Slowly — Fukuoka & Kyushu Road Trip 2026

A responsive, single-page Thai travel guide for 6–13 December 2026.

## Deploy to Vercel

1. Sign in to https://vercel.com/
2. Choose **Add New → Project**.
3. Import this folder from a GitHub repository, or use Vercel CLI from this folder.
4. Framework preset: **Other**. Build command: leave blank. Output directory: `.`.
5. Deploy. Vercel will provide a public `*.vercel.app` URL that you can share.

### Easiest route using GitHub
1. Create a new public or private GitHub repository.
2. Upload `index.html` to the repository root.
3. In Vercel, import that repository and deploy with the settings above.
